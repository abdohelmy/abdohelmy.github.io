# Abdelrahman Mohamed — academic website

A responsive, static academic portfolio for GitHub Pages. No build tools or JavaScript dependencies are required.

## Preview

Run `python3 -m http.server 8000` from this folder, then open http://localhost:8000.

## Publish on GitHub Pages

1. Create a public repository named `abdohelmy.github.io` under the `abdohelmy` account.
2. Upload `index.html`, `styles.css`, `.nojekyll`, and the `assets` folder to its `main` branch.
3. In **Settings → Pages**, select **Deploy from a branch**, then **main** and **/ (root)**, and save.
4. GitHub will publish the site at https://abdohelmy.github.io/ after deployment completes.

For a differently named repository, the same files also work under a GitHub Pages project path.

## Update content

- Edit `index.html` for your biography, publications, experience, and contact information.
- Edit `styles.css` for typography, colors, and layout.
- Replace `assets/Abdelrahman-Mohamed-CV.pdf` to update the downloadable CV.

Content and paper/code links were taken from the supplied CV. Google Scholar is linked directly; citation counts are not displayed because they could not be verified. The teaching-assistant date range follows the CV's employment heading; its conflicting course-year detail is omitted. Reference contacts are not repeated in the webpage; the original downloadable CV includes them.
